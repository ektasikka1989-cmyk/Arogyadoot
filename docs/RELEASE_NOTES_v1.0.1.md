# ArogyaDoot v1.0.1

Bug-fix release. Install over v1.0.0; do not uninstall first, so your records and the downloaded model are kept.

## Fixes
- **Mic:** speech now types straight into the text box instead of opening a popup.
- **Groq key:** saving the key no longer crashes the app, and "Saved" appears only when the key really is saved.
- **Privacy:** patient, card and register photos are no longer sent online, and camera photos no longer appear in the phone's Gallery.
- **Patient-list import:** handwritten lists are read again; Excel (.xlsx) files open directly; CSV files with Hindi text import correctly; numbers from different columns are no longer joined together.
- **Drug kit:** the count screen shows all 16 kit medicines instead of 11; expired batches are flagged "Do not give"; "syrup" no longer matches the wrong medicine.
- **Attachments:** the same card is no longer scanned twice, and photos that can't be read now show a clear message.
- **Demo:** demo steps that stopped working have been fixed.
